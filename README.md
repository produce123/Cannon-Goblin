# Cannon Goblin · 大炮轰小鬼

一个**不依赖任何服务器**的不对称策略棋盘游戏。纯静态页面（零依赖、零构建），
联机对战走 **WebRTC 点对点直连**，双方交换两段代码即可开局。

🎮 在线玩：**https://produce123.github.io/Cannon-Goblin/**

---

## 玩法

| | 大炮方 💣 | 小鬼方 👻 |
|---|---|---|
| 数量 | 2 枚 | 18 枚 |
| 先手 | ✅ | |
| 移动 | 横竖走一格到相邻空格 | 横竖走一格到相邻空格 |
| 吃子 | 隔**恰好一个空格**吃掉同一直线上的小鬼 | 不能吃子，只能围堵 |

**胜负**

- 大炮方获胜：场上小鬼数 **≤** 大炮数
- 小鬼方获胜：所有大炮都被堵死，一步也走不了

## 三种模式

- **本地对局** — 两人同一台电脑轮流走
- **人机对局** — 三档 AI：简单（随机）/ 普通（启发式）/ 困难（minimax 深度 3）
- **在线对局** — WebRTC 直连，见下

另外还有预设地图、自定义棋盘尺寸、以及可自由摆放初始棋子的地图编辑器。

## 在线对局怎么连（无需服务器）

因为家里没有公网 IP、也不想租服务器，这里**不用信令服务器**，
改成人工把两段握手代码转发一下。整局棋的数据全程点对点直连，不经过任何第三方。

**房主（执 💣 大炮方）**

1. 菜单 → 在线对局 → 选好地图 → 点 **生成邀请码**
2. **复制**那段邀请码，通过 QQ / 微信发给对手
3. 对手回传一段应答码后，粘贴到输入框，点 **连接对手**
4. 连上后自动进入棋盘，你先走

**加入方（执 👻 小鬼方）**

1. 菜单 → 在线对局 → 把收到的邀请码粘贴到右边输入框 → 点 **生成应答码**
2. **复制**生成的应答码，发回给房主
3. 房主点连接后，双方同时进入棋盘

> 只同步"一手棋"，不同步整个棋盘：双方本地跑同一套规则，所以流量极小（每步几十字节）。

### 连不上怎么办

连接只使用**公共 STUN**（Google / Cloudflare，负责探路，不中转数据），没有 TURN 中继。

- ✅ 常见情况（家庭宽带、同一条 WiFi）都能直接打通。
- ⚠️ 如果双方都在**对称 NAT** 后面（典型是手机 4G/5G 热点、部分公司网络），
  打洞会失败。此时需要一台 TURN 中继服务器：在
  [`js/webrtc.js`](js/webrtc.js) 的 `ICE_SERVERS` 里加一条即可，例如

  ```js
  { urls: 'turn:your.turn.server:3478', username: 'user', credential: 'pass' }
  ```

  （TURN 是可选项，没有也能玩，只是穿透率低一些。）
- 建议用 Chrome / Edge / Safari 等现代浏览器；内网老旧的 IE 内核不行。

## 本地运行

没有构建步骤，改完刷新即可。

```bash
# 推荐：起个本地静态服务器（localhost 属于安全上下文）
npx serve .
# 或
python -m http.server 8000
```

也可以直接双击 `index.html`。但 `file://` 下部分浏览器会限制 WebRTC 与剪贴板 API，
**联机建议走上面的本地服务器或直接用 GitHub Pages 地址**。

## 测试

```bash
node --test tests/game.test.mjs   # 单元用例
node tests/browser/run.mjs        # 真实浏览器端到端（自动找 Chrome / Edge）
```

**单元用例**覆盖信令编解码（往返、聊天工具插入换行/零宽字符、截断损坏、错误类型），
以及关键不变量：**双方各自本地重放同一串走子后局面必须完全一致** —— 这是在线对局
只同步"一手棋"的前提。

**浏览器 E2E** 会起一个临时静态服务器，用无头浏览器打开三个 iframe 各跑一份真实
`index.html`，完整走一遍「邀请码 → 应答码 → 自动开局 → 双方各走一手 → 再来一局 →
本地/人机冒烟」，并检查页面内没有任何被吞掉的 async 报错。

## 目录结构

```
index.html                所有界面（菜单 / 设置 / 编辑器 / 联机大厅 / 棋盘 / 规则）
css/style.css             所有样式
js/game.js                规则引擎 GameState + 预设地图
js/ai.js                  三档 AI
js/audio.js               WebAudio 合成音效（无音频文件）
js/webrtc.js              WebRTC 直连 + 邀请码/应答码编解码
js/app.js                 界面控制与对局收发
tests/game.test.mjs       node:test 单元用例
tests/browser/            无头浏览器 E2E
functions/                可选旧版后端（Supabase Edge Function），前端已不再使用
```
